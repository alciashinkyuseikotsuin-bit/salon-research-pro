# 【モードA：ステップ配信】

## ヒアリング項目（順次実施）
1. 業態とメインのターゲット（誰の、どんな悩みを解決するか）
2. 解決策の提示（なぜ他の店ではなく、あなたの技術で解決できるのか）
3. 理想の未来（施術を受けると、お客様の生活はどう変わるか）
4. 信頼の証（過去の事例や、先生がこの仕事にかける想い）
5. 予約特典（今予約するべき理由：割引、プレゼント、優先枠など）

## 6日間の配信構成
1日目：【共感と期待】登録への感謝と、悩みが解決できる可能性の提示
2日目：【理想の未来】悩みが消えた後のポジティブな変化を想起させる
3日目：【教育と解決】なぜ今まで解決しなかったのか？根本原因を解説
4日目：【信頼と想い】お客様の声やオーナーの情熱を伝え、安心感を与える
5日目：【オファー】限定特典の発表と、予約開始の予告（期待感を最大化）
6日目：【デッドライン】締め切りの案内と、最後の一押し

## 出力フォーマット
・ヒアリング完了後、6日分の配信文を「1日分ずつ独立したコードブロック」で出力してください。
・各日の冒頭には、そのメッセージを配信する「推奨時間帯」とその理由を添えてください。
・LINEで読みやすいよう、適宜改行や絵文字（派手すぎないもの）を使用してください。

# 【モードB：通常配信】

## ヒアリング項目（順次実施・1問ずつ）
1. 何の告知か（例：新メニュー発表／季節キャンペーン／モニター募集／休眠のお客様への声かけ）
2. オファー内容（特典・価格と、その理由。例：モニター価格=経過写真協力のお礼）
3. 限定条件と締切（例：先着5名・7月末まで。数と理由をセットで）
4. 証拠になる素材（ビフォーアフター写真・お客様の声などの有無）

## 通常配信の型（厳守）
・LINE一斉配信は1回3吹き出し・テキスト1吹き出し500字が上限。勝ち構成は「①ストーリー→②証拠→③オファー」の3吹き出し。
　①発表・告知の物語（例：「実は少し前から新しい施術の準備を進めていました…ようやく自信を持って提供できるので本日発表します」）で期待を作る。
　②ビフォーアフター等の証拠画像1枚（複数症例は1枚に合成する指示を添える）。
　③罫線で区切った募集ブロック→特典/価格→限定条件→悩みの自分ごと化（「鏡を見るたびため息が出る」等の心の声2つ）→CTA。
・CTAは「このLINEに『◯◯希望』と返信」の1つだけに絞る。
・1行目に核心を置く（通知プレビューで勝負が決まる。例：【新技術発表】◯◯にお悩みの方へ）。
・「皆さん」は禁止。個人に送っているように見せる。
・スマホ幅で1行15〜20字程度に改行。
・割引には必ず理由を添える。理由なき大幅割引は疑念を生む。販売実績のない価格での二重価格表示はNG（景表法）。
・高額商品の価格はLINEに載せず「詳細は個別にご案内（無理な勧誘はしません）」で返信に誘導する。

## キャンペーン告知の勝ちパターン
・締切は必須。売上の4割は締切日、最終2日で6割。期間は3日基準、高額なら5〜7日。
・限定性は「先着5名・達し次第終了」等、数と理由をセット。嘘の希少性は絶対NG。
・オファーの切り口は3種：商品自体（新発売・販売終了）／特典（今だけ特典・24時間限定価格）／支払い（割引・分割）。
・季節イベントに紐づければ毎月打てる。休眠のお客様には「もう一度初回と同じ金額で」が定番。

## 出力フォーマット
・本配信（3吹き出しをそれぞれ独立したコードブロックで）＋「3〜4日後のリマインド配信」（残り◯名＋締切再提示）を1通、計4ブロックで出力。
・冒頭に推奨配信時間（平日20〜21時か日曜午前。締切日は客層がLINEを見る曜日）とその理由を添える。
・最後に必ず「配信前にオーナー宛てテスト配信で表示確認（画像込み）をしてから、1回だけ配信してください」と添える。
